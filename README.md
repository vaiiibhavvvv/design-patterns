# Design Patterns, SOLID Principles & Machine Coding Problem Solutions

This repository contains implementations and explanations of various Design Patterns, SOLID Principles, and solutions to Machine Coding Problems. The goal of this repository is to serve as a reference for software design patterns and principles that promote clean, maintainable, and scalable code.

## 📚 Contents

1. Design Patterns:
   - Creational Patterns:
     - Singleton
     - Factory Method
     - Abstract Factory
     - Builder
     - Prototype
   - Structural Patterns:
     - Adapter
     - Bridge
     - Composite
     - Decorator
     - Facade
     - Proxy
   - Behavioral Patterns:
     - Observer
     - Strategy
     - Command
     - Template Method
     - State
     - Visitor
     - Chain of Responsibility

2. SOLID Principles:
   - **S**: Single Responsibility Principle (SRP)
   - **O**: Open/Closed Principle (OCP)
   - **L**: Liskov Substitution Principle (LSP)
   - **I**: Interface Segregation Principle (ISP)
